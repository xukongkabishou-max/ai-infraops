# Value 查看审批

业务系统管理和中间件系统管理各提供“我的审批记录”。环境变量按单个容器的单个 Key 申请；Nacos 按实例、Namespace、Group、Data ID 对应的一整份配置申请。申请原因必填。

后台“审计日志”下方的“Key 查看审批”统一查看申请人、类别、环境、目标、申请时间及审批结果。审批权限为 `value:approve`，初始化授予 `ops` 和 `super_admin`。不能审批自己的申请。管理员可同意或拒绝并填写备注。

同意时读取源服务当前值并加密保存快照。环境变量记录实际采集的 Pod、容器及 Key；Nacos 保存完整配置文本。采集失败时保持待审批，允许重试。默认有效期 60 分钟，可选 5 至 1440 分钟，从采集完成时间开始计算。重复审批通过数据库条件更新保护。

申请人只能查询自己的记录和读取自己的已批准快照。接口每次读取都检查当前账号、角色权限、源实例状态及 Namespace 白名单；服务端阻止过期读取，前端自动隐藏到期值。显示申请、审批、采集及到期时间（接口 UTC，页面本地时间）。审批列表不含明文，快照使用 AES-GCM 加密且附加数据绑定申请 ID，响应禁止缓存，审计日志仅记录操作元数据。

已展示的值无法从用户自行复制的副本中收回；有效期控制本系统中的后续访问，不会实时更新快照。

数据库变更：`services/backend/sql/018_value_access_requests.sql`。已有环境只执行此增量迁移，避免重跑初始化脚本重置现有账号。后端注册接口后需重新加载服务。

验证：`python -m pytest tests/test_value_access.py tests/test_k8s_client.py`，以及两个前端的 TypeScript 和 ESLint 检查。测试覆盖两类申请、用户隔离、未审批拒绝读取、非管理员拒绝审批、自审批限制、过期、权限撤回、采集失败、加密及快照绑定。
